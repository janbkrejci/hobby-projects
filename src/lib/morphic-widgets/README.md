# Morphic Widgets

Toto je sada widgetů pro [morphic.js](https://github.com/jmoenig/morphic.js) a demo stránka.

## Jak spustit

Stačí otevřít soubor `index.html` ve vašem prohlížeči. Není potřeba žádný server.
