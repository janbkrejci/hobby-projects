# Neural Network Playground

This folder contains the TypeScript implementation of the perceptron and a
simple feedforward neural network used by the `/neural-network` demo.

## Structure

- `Perceptron.ts` contains the core perceptron implementation and activation functions.
- `NeuralNetwork.ts` wires perceptrons into a configurable multi-layer network.

## Origin

The code is based on the `external/NeuralNetwork` submodule and adapted to the
Next.js app conventions used in this repository.
