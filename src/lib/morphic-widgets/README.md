# Morphic Widgets

Sada widgetů pro [morphic.js](https://github.com/jmoenig/morphic.js) s demo stránkou.

## Jak spustit

V rámci tohoto projektu je demo dostupné na `/morphic-widgets/index.html`.
Soubor `index.html` očekává `morphic.js` z upstreamu a načítá ho přes interní
route proxy kvůli správnému `Content-Type`.

## Poznámka

`morphic.js` je záměrně pouze externí závislost (raw GitHub), aby šlo snadno
aktualizovat upstream bez kopírování do repo.
